# 📖 README – If The Shoe Fitz ## 1. Présentation du projet **If The Shoe Fitz** est une boutique en ligne spécialisée dans la vente de sneakers. Le projet a pour ambition de proposer une **expérience e-commerce moderne**, simple, et adaptée aussi bien aux clients finaux qu’aux gestionnaires de stock. Le site est construit sur **WordPress + WooCommerce**, avec une logique de personnalisation via un **thème enfant** pour séparer le code source du thème parent et les modifications spécifiques au projet. --- ## 2. Objectifs du projet - Créer une plateforme e-commerce dédiée aux sneakers (hommes, femmes, enfants, unisex). - Offrir une **navigation fluide** et **un catalogue clair**. - Permettre aux vendeurs de **gérer les stocks depuis le front-office** (parcours simplifié, sans accès complet au back-office WordPress). - Proposer une **expérience client multilingue** (français/anglais). - Construire une base solide et **scalable** pour de futures évolutions. --- ## 3. Fonctionnalités principales ### Côté client - Consultation du catalogue (page Boutique, catégories, produits individuels). - Filtrage par catégories : **Men**, **Women**, **Kids**, **New Releases**. - Ajout au panier et passage de commande via **Checkout** sécurisé. - Gestion du compte client simplifiée avec accès uniquement à : - **My Account** (dashboard) - **Account Details** (informations personnelles) - **Log Out** (déconnexion) ### Côté vendeur/administrateur - Gestion des produits par catégories, variantes (taille, couleur) et stock. - Interface vendeur simplifiée via un plugin de gestion front-office. - Personnalisation du contenu et des traductions via thème enfant. - Possibilité d’évolution (nouvelles pages, intégrations marketing). --- ## 4. Architecture technique - **CMS** : WordPress - **E-commerce** : WooCommerce - **Thème parent** : structure de base (styles, gabarits) - **Thème enfant** : - Personnalisation du **header** (suppression d’images par défaut) - Personnalisation du **footer** (Quick Links vers pages et catégories) - Nettoyage du menu **Mon Compte** (réduction à 3 entrées) - Traductions (FR → EN) - **Plugins clés** : - WooCommerce (obligatoire) - WCFM ou équivalent (Frontend Stock Management) - Loco Translate (traductions) - Elementor/Gutenberg (mise en page) --- ## 5. Navigation et structure ### Pages principales - **Boutique générale** : `/shop` - **Catégories produits** : - Men → `/product-category/men` - Women → `/product-category/women` - Kids → `/product-category/kids` - New Releases → `/shop` (redirigé vers la boutique) - **Panier** : `/cart` - **Checkout** : `/checkout` - **Mon Compte** : `/my-account` ### Footer – Quick Links Bloc **Shop** avec entrées cliquables : - All Products → Boutique - Men → Catégorie Men - Women → Catégorie Women - Kids → Catégorie Kids - New Releases → Boutique --- ## 6. Contenu produit - **Variantes par tailles** : - Enfant : 27–37 - Femme : 37–47 - Homme : 37–47 - Unisex : 37–47 - **Variantes par couleurs** : chaque produit dispose de 3 déclinaisons. - **Images produits** : importées depuis collections Unsplash (sneakers populaires). --- ## 7. Maintenance et évolutivité ### Bonnes pratiques - Toujours modifier via le **thème enfant**. - Sauvegardes régulières (base de données + fichiers). - Vérifier la compatibilité des mises à jour WordPress/WooCommerce/plugins. - Tester les traductions après ajout de nouvelles chaînes. ### Évolutions possibles - Création d’une vraie catégorie **New Releases**. - Intégration d’un système de recommandations produits. - Connexion avec un ERP pour automatiser la gestion des stocks. - Mise en place de campagnes marketing (newsletter, promos). --- ## 8. Guide rapide pour les équipes ### Ajouter un produit 1. Aller dans **Produits → Ajouter**. 2. Remplir titre, description, prix. 3. Ajouter images produit. 4. Sélectionner la catégorie (Men, Women, Kids, Unisex). 5. Définir les variations (taille + couleur). 6. Sauvegarder. ### Gérer le stock - Utiliser l’interface WCFM (front-office) → champ “Stock disponible” pour chaque produit. ### Modifier le footer (Quick Links) - Fichier du thème enfant : `template-parts/footer/...`. ### Modifier le header - Surcharger `header.php` dans le thème enfant et retirer les images non désirées. --- ## 9. Conclusion **If The Shoe Fitz** est une base e-commerce robuste et flexible. Grâce à l’usage d’un thème enfant et de WooCommerce, la boutique peut évoluer facilement (ajout de catégories, gestion avancée du stock, intégration marketing). Le projet vise à allier **simplicité côté utilisateur** et **efficacité côté vendeur**, avec une architecture claire, bien documentée et prête à grandir.
